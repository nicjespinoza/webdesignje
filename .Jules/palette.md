## 2024-05-19 - Added ARIA labels and focus styles to icon-only buttons in Profile Components
**Learning:** Found multiple icon-only buttons (Trash, Eye, Back, StickyNote, Activity) in the patient profile components (`PatientHeader.tsx`, `HistoryList.tsx`, `ConsultList.tsx`) that had no screen-reader readable text and were missing explicit focus indicators for keyboard navigation. A pattern was also discovered where elements that are hidden visually (using `opacity-0` and `group-hover:opacity-100`) also need `focus-within:opacity-100` on the parent or `focus-visible:opacity-100` on the element itself so they become visible to keyboard-only users when focused.
**Action:** When adding icon-only buttons, especially those that appear on hover, ALWAYS add an `aria-label`, a `title` (for mouse hover tooltips), and `focus-visible:ring-2 focus-visible:outline-none focus-visible:opacity-100` classes so keyboard users can navigate to and see the interactive element. Always extract the text into the translation files instead of hard-coding them.
