## 2025-02-12 - Added ARIA Label and Focus styles to Mobile Menu Toggle button
**Learning:** For interactive UI elements toggling menus, ensure correct usage of `aria-expanded` and `aria-controls`, and include accessible names for buttons when their contents are only icons by using `aria-label`. We also used `aria-pressed` for the language toggles on the NavBar. We also added `focus-visible:ring-[#C69320]` to allow users who navigate via keyboards to quickly see what element currently has focus.
**Action:** When creating menu toggles or buttons containing icon-only elements, provide appropriate ARIA roles and add clear keyboard focus indicators. Wait to check whether language translation functions require localized strings. Ensure you run your changes through accessibility checks manually.
