## 2026-06-28 - Improve Accessibility of Navbar Mobile Menu Toggle and Language Selectors
**Learning:** Icon-only buttons (like the mobile menu toggle) and interactive elements that function as language selectors lack proper ARIA attributes, making them inaccessible to screen reader users. The language buttons also lacked `aria-pressed` states to indicate selection, which is a common a11y gap for custom radio button groups.
**Action:** When implementing custom icon buttons or interactive menu toggles, always include `aria-expanded`, `aria-label`, or `aria-controls`. When creating custom radio or toggle button groups (like language selectors), include `aria-pressed` to communicate the selected state to assistive technologies. I'll add `aria-expanded` and `aria-label` to the mobile toggle, and `aria-pressed` and `aria-label` to the language buttons in the Navbar.
