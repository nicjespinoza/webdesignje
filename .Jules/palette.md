## 2024-07-29 - Mobile Menu Toggle Accessibility Improvements
**Learning:** Icon-only buttons for critical navigation elements (like mobile menus) often lack accessible names, making them invisible or confusing to screen reader users. Furthermore, missing focus states (`focus-visible`) severely hinder keyboard navigation. Using ARIA attributes like `aria-expanded` and `aria-controls` explicitly links the toggle button to the menu content, providing essential context to assistive technologies.
**Action:** When creating or reviewing interactive elements, especially icon-only toggles, always ensure they have dynamic `aria-label`s, track state via `aria-expanded`, link to their controlled content via `aria-controls`, and include visible focus indicators (e.g., `focus-visible:ring-2`).
