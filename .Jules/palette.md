## 2024-05-29 - Screen Reader Accessibility for Dynamic Modals & Interactive Menus
**Learning:** Icon-only interactive elements like language selectors (using flag images and abbreviations) or hamburger menus must always include an explicit `aria-label` or `title` to ensure the action is announced clearly by screen readers. State-based interactivity (like selected language or open/closed mobile menu states) should rely on `aria-pressed` or `aria-expanded` attributes respectively to communicate the component's current status programmatically. Also, `focus-visible` styles should always be applied to custom interactive controls to maintain keyboard navigation visibility.
**Action:** When creating custom interactive buttons, especially for layout components like Navbars or Modals, proactively add `aria-expanded`/`aria-controls` for toggles and `aria-pressed` for selectable buttons to make state changes accessible. Include `focus-visible:ring-2` to guarantee keyboard accessibility is not lost.
