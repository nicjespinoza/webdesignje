## 2024-04-28 - Accessibility and Internationalization for Icon-Only Buttons
**Learning:** Icon-only buttons used for secondary actions (like "View" eyes next to primary buttons) often lack text descriptions, which creates an accessibility gap for screen readers and tooltips. Hardcoding these strings breaks internationalization.
**Action:** When adding `aria-label` and `title` to icon-only buttons, always check for the existing `useAppTranslations` hook (e.g. `import { useAppTranslations } from '@/hooks/useTranslations'`) and map the strings to the translation dictionaries (`messages/es.json` and `messages/en.json`) instead of hardcoding Spanish strings. Combine this with keyboard-accessible focus states (`focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-primary`).
