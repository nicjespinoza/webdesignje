## 2024-07-12 - Navbar Accessibility Navigation
**Learning:** In highly interactive custom navigations (like dual mobile/desktop language selectors or animated mobile menus), standard keyboard accessibility features like `focus-visible` states and accurate ARIA attributes (`aria-pressed`, `aria-expanded`, `aria-controls`) are critical for screen reader users and keyboard navigation. Using tailwind utilities like `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-[#C69320]` perfectly matches the existing design system while solving navigation barriers.
**Action:** Always implement `aria-pressed` for single-choice toggle button groups (like language selectors) and pair menu toggles with `aria-expanded` and `aria-controls`. Also ensure `focus-visible` styling is included on all custom buttons.
