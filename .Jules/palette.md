## 2024-08-16 - Accessible Language Selectors and Mobile Toggles
**Learning:** Icon-only mobile toggles and complex UI controls (like language selectors with flags) lack clear context for screen reader users without proper ARIA attributes (`aria-label`, `aria-expanded`, `aria-controls`), and fail to convey their current state without `aria-current`. Furthermore, lacking keyboard focus rings reduces accessibility for keyboard navigators.
**Action:** Always ensure interactive elements, especially toggles and selectors without explicit text labels, include descriptive ARIA labels, state attributes, and keyboard focus styles (`focus-visible:ring-2 focus-visible:ring-[#C69320] focus-visible:outline-none`). Connect toggle buttons to their corresponding menus using `aria-controls` with matching DOM IDs.
