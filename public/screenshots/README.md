## Cómo Tomar las Screenshots:

### Windows:
1. Abrir la demo en tu navegador
2. Presionar `Win + Shift + S`
3. Seleccionar el área a capturar
4. Guardar en esta carpeta con el nombre correspondiente

### Herramienta Online:
- https://screenshot.guru (gratis, sin marca de agua)

### Chrome Extension:
- "GoFullPage" para capturas completas

---

## Una Vez Agregadas:

1. Recargar el navegador: `Ctrl + Shift + R`
2. Verificar que se vean en la sección "Proyectos Destacados"
3. Si no se ven, revisar que los nombres sean exactos
