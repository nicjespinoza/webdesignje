## 2026-03-01 - Adding ARIA labels to icon-only buttons\n**Learning:** When improving accessibility, `aria-label` attributes should only be added to interactive elements that lack visible text content (e.g., icon-only buttons). Adding `aria-label` to buttons that already have visible text overrides that text for screen readers, which is an accessibility anti-pattern as it violates WCAG 2.5.3 (Label in Name).\n**Action:** Always verify if a button or link has visible text before blindly applying `aria-label`. Reserve `aria-label` for elements whose purpose is purely conveyed through icons or visual design.
