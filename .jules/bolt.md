## 2024-06-25 - distanceTo vs distanceToSquared in high-frequency rendering loops
**Learning:** In Three.js and React Three Fiber environments, calculating distances using `distanceTo` relies on `Math.sqrt`, which is a highly expensive operation when performed in O(n^2) nested loops (e.g., determining node connections among 120 nodes = 14,400 iterations per frame or memoization).
**Action:** Always prefer `distanceToSquared` and compare against the threshold squared (`distSq < threshold * threshold`) to eliminate `Math.sqrt` overhead in high-frequency logic or large iteration blocks within 2D/3D scenes. Ensure you don't inadvertently modify iteration boundaries that govern rendering aesthetics (like skipping redundant reverse line calculations where accumulating opacities may rely on duplicate visual lines).
