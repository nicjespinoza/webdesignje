## 2024-05-27 - Distance Squared Optimization
**Learning:** In Three.js and high-frequency React loops (`useFrame`), using `distanceTo` requires calculating the square root `Math.sqrt()` which can severely impact performance in `O(n^2)` distance checks (e.g. iterating over all particle nodes in a network).
**Action:** Replace `distanceTo` with `distanceToSquared` in all inner animation loops or distance-checking nested loops (`useFrame`, etc.). Make sure to square the `threshold` variable you are comparing it against. Do not use `Math.sqrt()` if you can avoid it inside hot rendering paths. Note: Check memory if modifying `n1.layer` connection generation iterations (`j = i + 1`) because halving iterations can cause visual regressions in Three.js where accumulated line opacity is desired!
