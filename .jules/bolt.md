## 2024-03-24 - Distance Calculation Optimization in WebGL loops
**Learning:** O(n²) nested loops in Scene3D animations running inside `useFrame` or `useMemo` calculate distances using `Math.sqrt()` via Three.js's `distanceTo()`. With hundreds of particles (neurons/agents), calculating exact distances when only threshold comparisons are needed creates a severe CPU bottleneck in the JavaScript thread, dropping frame rates.
**Action:** Always replace `distanceTo(v) < threshold` with `distanceToSquared(v) < threshold * threshold` in Three.js and Canvas applications. In high-frequency rendering loops, calculate the `thresholdSquared` once outside the loop to avoid redundant `Math.pow` or multiplication operations. This significantly reduces CPU load during continuous rendering.
