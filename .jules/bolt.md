## 2025-03-02 - Squared Distance Comparisons in Canvas Render Loops
**Learning:** In 2D Canvas components calculating distance between particles in `requestAnimationFrame` loops (especially O(n^2) nested loops for line connections), using `Math.sqrt()` is relatively expensive. We can optimize this by comparing squared distances (`distSq < threshold * threshold`) instead of calculating the actual distance, unless the actual distance is strictly needed for opacity or stroke width. Even when the actual distance is needed, pre-filtering with a squared distance check first can skip the `Math.sqrt()` calculation for the vast majority of particle pairs that are far apart.
**Action:** Replace `Math.sqrt(dx * dx + dy * dy) < threshold` with `(dx * dx + dy * dy) < (threshold * threshold)`. Note: Hoist `threshold * threshold` if possible.
