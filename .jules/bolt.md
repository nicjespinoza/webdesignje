## 2024-05-24 - Optimize Three.js High-Frequency Distance Calculations
**Learning:** In Three.js applications (like Scene3D component), using `distanceTo` within nested O(n^2) loops or `useFrame` animation loops creates a significant performance bottleneck due to the computationally expensive `Math.sqrt` operation under the hood. Furthermore, checking connections bidirectionally in an O(n^2) loop causes redundant processing and visually overlapping identical lines.
**Action:** Always prefer `distanceToSquared(v) < threshold * threshold` instead of `distanceTo(v) < threshold` in high-frequency rendering loops. When generating connections between nodes, use `i < j` logic (e.g. `for (let j = i + 1; j < nodes.length; j++)`) instead of nested `forEach` loops to halve the total iterations and prevent duplicated line rendering.
