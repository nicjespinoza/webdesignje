## 2024-05-18 - Optimized Three.js Animation Loops
**Learning:** In Three.js and React Three Fiber environments, continuously instantiating new instances of complex objects (like `new THREE.Vector3()`) inside high-frequency `useFrame` or `requestAnimationFrame` loops triggers significant garbage collection (GC) activity. This can cause the browser to periodically pause animation threads to clear memory, resulting in visible framerate drops and micro-stutters.
**Action:** When performing calculations inside a high-frequency loop, declare a single reusable `THREE.Vector3` object outside the loop (using `useMemo` in functional components) and mutate it using methods like `.subVectors()`, `.copy()`, or `.set()`. Additionally, replace `.distanceTo()` with `.distanceToSquared()` when comparing against thresholds to avoid expensive `Math.sqrt` evaluations on every frame.
