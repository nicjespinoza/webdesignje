## 2024-05-24 - Three.js Distance Calculation Optimization
**Learning:** In Three.js applications, replacing `distanceTo()` (which computes square root) with `distanceToSquared()` avoids expensive `Math.sqrt` calls inside high-frequency animation loops (`useFrame`) and nested O(n^2) calculations (`useMemo`), leading to measurable performance improvements without functional differences. Also, halving iterations in O(n^2) node connection loops (e.g., `j = i + 1`) can cause visual regressions if rendering logic relies on duplicate line pairs for opacity accumulation.
**Action:** Always prefer squared distance comparisons (`distSq < threshold * threshold`) over absolute distances for proximity checks inside animation frames or large iteration blocks. Avoid changing iteration bounds on legacy visual effects without verifying opacity behavior.
