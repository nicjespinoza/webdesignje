## 2024-05-14 - 3D Scene Distance Calculation Optimization
**Learning:** In Three.js and Canvas applications with high-frequency animation loops or nested O(n^2) loops (like calculating connections between nodes), using `Math.sqrt` (via `distanceTo()`) introduces significant computational overhead. Furthermore, generating node connections symmetrically across permutations can double rendering work unnecessarily. However, loop halving (`j = i + 1`) cannot be blindly applied if the connection criteria (like threshold or strength) rely on properties specific to the source node.
**Action:** When calculating distances in high-frequency loops or for threshold comparisons, always use `distanceToSquared()` and compare against the squared threshold (`threshold * threshold`). When generating non-directional connections, attempt to halve iterations using `for (let j = i + 1; j < nodes.length; j++)`, but verify that connection rules are symmetric before doing so.
