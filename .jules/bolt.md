## 2025-05-22 - Replacing Three.js distanceTo with distanceToSquared
**Learning:** In Three.js and similar 2D/3D applications, `distanceTo` calculates the exact Euclidean distance involving a computationally expensive `Math.sqrt()` call. When evaluating thresholds in high-frequency animation loops (like inside `useFrame`) or nested arrays $O(N^2)$, replacing `distanceTo(v) < threshold` with `distanceToSquared(v) < threshold * threshold` avoids the square root computation and significantly improves rendering performance.
**Action:** Always replace basic distance calculations with squared distance comparisons inside high-frequency animation loops or nested loops. Keep in mind not to blindly alter iteration loops (`j = i + 1`) to `j = 0` if logic depends on duplicates for opacity.
