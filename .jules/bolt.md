## 2025-05-18 - Optimize Three.js Scene Graphs and Loops
**Learning:** High-frequency animations (like `useFrame`) and nested `useMemo` hooks calculating positions should aggressively avoid operations like `Math.sqrt()` implicitly called by `.distanceTo()`. Using `.distanceToSquared()` with squared thresholds avoids expensive square root math. Furthermore, calculating undirected connections between points in O(n²) loops (like mapping synapses between neurons) will compute (A,B) and (B,A), causing redundant logic and potentially double the rendered objects unless deduplicated.
**Action:** When building nested loops for undirected connections in Three.js/Canvas, use an index offset `for (let j = i + 1; j < nodes.length; j++)` to halve iterations and prevent duplicate mapping. Inside render loops or physics logic, always prefer `distanceToSquared` over `distanceTo`.
