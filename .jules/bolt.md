## 2026-03-16 - Squared Distance Optimizations in Animation Loops
**Learning:** In high-frequency 60fps animation loops (like in `components/Scene3D.tsx`, `components/ParticleBackground.tsx`, and `components/FooterParticles.tsx`), repeatedly calling `Math.sqrt` to calculate distances creates a measurable performance bottleneck, especially as the number of nodes/particles increases. The Three.js `distanceTo()` function uses `Math.sqrt` internally. By comparing squared distances (`distanceToSquared()` or `dx*dx + dy*dy < radius*radius`), we avoid the expensive square root operation entirely unless it is specifically required for calculating derived values like force or opacity.
**Action:** Always use squared distance comparisons (`distanceToSquared()` for Three.js vectors, or `distanceSq < radius*radius` for 2D vectors) inside hot loops (like `requestAnimationFrame` or `useFrame`) to determine proximity before computing the actual square root.
